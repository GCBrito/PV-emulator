Before using the emulator, install and configure the OwnTech development environment by following the official **[OwnTech Environment Setup](https://docs.owntech.org/latest/core/docs/environment_setup/)** instructions.

The firmware is developed and compiled using PlatformIO within Visual Studio Code.

# Emulator Configuration

Before compiling the firmware, configure the photovoltaic-module parameters directly in `main.cpp`.

For the **Simplified Exponential Model**, the following four characteristic quantities must be provided:

```math
V_{\mathit{mpp}}^{\mathit{ref}},
\qquad
I_{\mathit{mpp}}^{\mathit{ref}},
\qquad
V_{\mathit{oc}}^{\mathit{ref}},
\qquad
I_{\mathit{sc}}^{\mathit{ref}}
```

All four quantities must correspond to the same environmental operating condition.

For the **Single-Diode Model**, configure the manufacturer-datasheet quantities in the `PV MODULE REFERENCE PARAMETERS` section of `main.cpp`, including the characteristic voltages and currents, reference irradiance and temperature, number of cells in series, and temperature coefficients.

The desired environmental operating condition is defined separately through $G$ (irradiance to be emulated) and $T$ (the PV-module cell temperature).

The detailed input parameters required by each implementation are described in their corresponding README files:

- **[Simplified Exponential Model](Simplified%20exponential%20model/)**
- **[Single-Diode Model](Single-diode%20model/)**

# Operating the Emulator

After uploading the firmware, open **PlatformIO: Serial Monitor**.

<p align="center">
  <img
    src="https://github.com/user-attachments/assets/37ac49fb-9c28-4813-939c-0ef9333b5922"
    alt="PlatformIO Serial Monitor"
    width="900"
  />
</p>

The firmware provides three main operating modes:

- Press `i` to enter **Idle Mode**. The PWM signals are disabled and no power conversion is performed.
- Press `p` to enter **Power Mode**. The TWIST board operates as a conventional voltage-regulated Buck converter.
- Press `e` to enter **Emulator Mode**. The emulator identifies the connected load, determines its operating point on the selected photovoltaic characteristic, and regulates the converter output accordingly.

Press `h` to display the available serial commands.

When using the **Single-Diode Model**, pressing `s` displays the five parameters identified by the numerical solver:

```math
I_{\mathit{ph}}^{\mathit{ref}},
\qquad
I_s^{\mathit{ref}},
\qquad
A,
\qquad
R_s,
\qquad
R_p
```

These parameters are calculated automatically when the firmware starts using the Levenberg–Marquardt solver.

# Safety

Before enabling the converter, configure appropriate voltage and current limits on the external DC source. The source, OwnTech platform, connected load, cables, and measurement equipment must all remain within their admissible electrical limits.

Because the TWIST is operated as a Buck converter, the input voltage $V_{\mathit{in}}$ must be sufficiently higher than the largest output voltage that the emulator is expected to regulate. In particular, this includes the load-identification test voltage $V_{\mathit{out}}^{\mathit{test}}$.

For the Single-Diode Model,

```math
V_{\mathit{out}}^{\mathit{test}}
=
1.05 \cdot V_{\mathit{oc}}^{\mathit{est}}
```

while the Simplified Exponential Model uses

```math
V_{\mathit{out}}^{\mathit{test}}
=
1.10 \cdot V_{\mathit{oc}}^{\mathit{ref}}
```

The selected value of $V_{\mathit{in}}$ must therefore provide sufficient voltage headroom for the converter while remaining within the allowable input-voltage range of the OwnTech hardware.

The TWIST power stage is rated at **300 W**, and each low-side channel is rated at **8 A**. Since the two low-side channels are connected in parallel for the PV emulator, the theoretical combined current limit is 16 A. However, the **300 W power rating and individual channel limits must also be respected**, and these constraints may become more restrictive than the total-current limit depending on the operating voltage.

The electrical limits of the connected device must be known before enabling Emulator Mode, even though its equivalent resistance is initially unknown to the emulation algorithm. The test voltage and resulting current must remain within the admissible limits of the connected device.

For sensitive devices, or when these limits cannot be reliably guaranteed, a lower test voltage or a gradual current-limited identification procedure should be used instead.

# PV Emulator Test: Reproducing a Photovoltaic $I-V$ Characteristic

A simple experimental validation consists of using a variable resistive load to reproduce different operating points along the photovoltaic $I-V$ characteristic.

For each connected resistance, the emulator identifies the corresponding load line and determines its intersection with the photovoltaic characteristic. By changing the resistance and recording the resulting output voltage and current, multiple points of the emulated $I-V$ curve can be experimentally obtained.

## Procedure

1. Select the PV module to be emulated and configure the corresponding firmware parameters.

2. When using the Single-Diode Model, define the desired irradiance $G$ and cell temperature $T$.

3. Configure the DC-source voltage and current limits and verify that all equipment ratings are respected.

4. Start with a **relatively high load resistance**, corresponding to an operating point closer to the open-circuit region of the photovoltaic characteristic.

5. Activate **Emulator Mode** by pressing `e` and wait for the emulator to establish the operating point.

6. Measure the output voltage $V_{\mathit{out}}$ and current $I_{\mathit{out}}$ using the external measurement instruments.

7. Gradually **decrease the load resistance** and repeat the measurement after each new operating point has stabilized.

8. Continue toward the high-current region only while remaining within the current, voltage, and power limits of the emulator, DC source, load, and measurement equipment.

9. Plot the measured pairs

```math
\left(
V_{\mathit{out}},
I_{\mathit{out}}
\right)
```

using software such as Python, MATLAB, or a spreadsheet application.

Starting from a high resistance and progressively decreasing it moves the operating point from the region close to the open-circuit voltage toward the high-current region of the $I-V$ characteristic. An actual short circuit should not be applied unless the complete experimental setup is specifically designed and rated for this condition.
